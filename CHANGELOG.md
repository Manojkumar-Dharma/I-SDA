## 0.11.0 and later

- **0.18.12** — E11h1: **fields, constants, help areas and formats of System/36 `DSPF36` source can be deleted, duplicated and reordered.** Panel buttons and the Delete and Ctrl+D keys; several selected fields are deleted in one edit; a duplicated format gets a free name; deleting a format asks first and the last format stays. Each is one edit, so one undo in the editor. Adding and dragging follow in E11h2 and E11h3.
- **0.18.11** — E11g4: **the help (H specification) panel of System/36 `DSPF36` source can be edited.** A format lists its help areas (click one to open it) and shows each `*DDS` block as a locked item. The panel edits online document, name or label, help file and library (or document and folder), the two corners as one edit (all four or none, for a null area), suppress selection, restore display format and boundary, each with its column numbers; names are checked against the manual and a refused value changes nothing. Breadcrumb words are Format and Help area for this source.
- **0.18.10** — E11j1: **System/36 `DSPF36` source gets rule checks in the Problems panel.** New `src/sfgrDiagnostics.js`: column values outside what the manual allows (S, H and D specifications, key mask included), a duplicate format name (any case), an X in column 80 with no line after it, a field outside its format's screen (the wrap respected), two fields on the same cells, and what the parser could not read (an unreadable line, a spec before the first S, a number that is not a number, text past column 80, a tab); six `isda.sfgr*` codes under the existing `isda.diagnostics.enable` and `isda.diagnostics.severity` settings; the sample `stipfm.dspf36` has none. - **0.18.7** — E11g2: **the format (S specification) panel of System/36 `DSPF36` source can be edited.** Selecting a format shows its name, start line (blank, 1 - 24 or 27, or V), lines to clear, 132 columns, right-to-left, lowercase, return input, the six Y / N / indicator columns (sound alarm, blink cursor, erase input, override, suppress input, null fill: No, Yes or an indicator 01 - 99), enable function keys and enable command keys (blank, Y, N, R, each with a line saying what it means), and the key mask as toggle buttons (function keys 1 - 6, command keys A - Y with their CF numbers; a character that is not a key is shown marked and can be removed). Input is checked first and refused with a message and no edit: a name (up to 8 characters, A - Z 0 - 9 # $ @ _, not starting with a digit, not another format's), start line and lines to clear within 24 (27 on a 132-column format), an indicator outside 01 - 99, a key mask over 16 characters. Renaming keeps the format selected. Fields and constants stay read-only until E11g3. New `e11g2SfgrFormatPanel.test.js` (54 checks in jsdom on the real sample; each edit and its undo give the original source back byte for byte).

- **0.16.5** — E2c *(tests, no behaviour change)*: new `src/compileLineMap.js`, which puts each compile message on the line of the source it belongs to, for the error-feedback loop. The listing's sequence numbers are the member's own, not the digits in columns 1-5, so a message is mapped by the ordinal of its listed line (the Nth listed line is the Nth source line, comments and blank lines included) and checked against the text the listing printed; if the source changed since the compile the lines are matched by a diff so messages follow their lines, and a line that was itself edited goes global instead of landing on a neighbour. - **0.16.4** — E2i *(tests, no behaviour change)*: new `src/compileListing.js`, which fetches the compile listing of a failed compile for the error-feedback loop. Names are validated before they reach a command, and nothing rejects. Nothing calls it yet - E2d does. `jobDateFormat.js` now also exports `ensureLibraryStandalone`.
